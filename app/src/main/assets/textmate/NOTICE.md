# Third-party grammars

Syntax highlighting grammars bundled with GitPockit:

- All `*.tmLanguage.json` files come from the Visual Studio Code repository
  (https://github.com/microsoft/vscode, tag 1.95.3, `extensions/*/syntaxes`),
  Copyright (c) Microsoft Corporation and contributors, licensed under the MIT License.
  Several are themselves derived from other projects as noted inside each file.
- `kotlin/Kotlin.tmLanguage` comes from the sora-editor project
  (https://github.com/Rosemoe/sora-editor, commit 94f3937edf225a4f15fc637fc94292a4d9e3e4b1).

The `gitpockit-dark.json` and `gitpockit-light.json` editor themes are original to GitPockit (GPL-3.0).
